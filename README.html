Bakery order tracker

Start the app

  1. Open Terminal in the folder that contains app.py.
  2. Run python3 app.py. On Windows, try python app.py.
  3. Open the bakery tracker in your browser. Leave Terminal open while you work.

Press Control+C in Terminal to stop the app. Decisions are saved as you go.

Work through the Instagram inbox

  1. Choose a day from November 23–29, 2026. The inbox shows messages received on that day and earlier. Use the days in order to work through the week as it unfolds.
  2. Check the pickup schedule for active orders, remaining baking time, and the value of confirmed orders. Pickups extend into December 1.
  3. Accept or reject each request. When Accept is disabled, the card explains the reason. A change or cancellation needs one active order with the same customer name and pickup date. Once you accept it, the schedule updates immediately.
  4. Use Book helper on a pickup day when you need more capacity. Each day can have one helper.

Each order contains one product type. Baking time is scheduled on the pickup date. Each day has eight hours of capacity. A $100 helper booking adds four hours of capacity for that date. The schedule shows order revenue and the helper fee separately.

Two days’ notice means a difference of at least two calendar dates. The app measures customer notice from the date the DM arrived and helper notice from the selected inbox day. Opening another inbox day changes the messages you can see and the date used for helper bookings. Decisions and bookings are shared across all views.

Implementation

app.py uses only the Python standard library. It serves HTML, CSS, and a small JavaScript inbox filter locally. Python checks notice, matching orders, and available capacity before saving changes. The app uses fixed rules and never sends replies to Instagram.

On first launch, the app creates bakery.db and imports 13 confirmed orders from existing_orders.csv and 25 pending messages from the seven InstagramOrders_*.html files. Keep those files beside app.py for the first launch. Later launches use the saved database. To back up your work, stop the app and copy bakery.db.
